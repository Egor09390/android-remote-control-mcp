# S23 Control для MCP-клиентов

ChatGPT или другой совместимый MCP-клиент сам выбирает действия. S23 Control
возвращает состояние экрана и выполняет команды над Android. Для подключения
из ChatGPT настройте CloudPub в приложении и добавьте выданный URL как MCP-сервер
с OAuth.

Штатные команды Android MCP доступны сразу после запуска. Основной способ
прочитать экран — `android_get_screen_state`. Он возвращает дерево с подписями,
идентификаторами и границами элементов в пикселях. Для нажатия по идентификатору
используйте `android_click_node` или `android_tap_node`.
`android_capture_screenshot` возвращает дерево и снимок для экрана, где нужны
детали изображения или отсутствующего в дереве элемента. Доступ к снимку
отключается переключателем «Снимки экрана по запросу» в настройках S23 Control
при остановленном MCP.

Дополнительные команды ARTEMIS выполняют отдельные действия, например нажатие,
свайп или ввод текста. При первом вызове такой команды S23 Control сам скачивает
ARM64-среду, проверяет её SHA-256 и запускает локальный исполнитель.
Ключ модели на стороне телефона не вводится.

Исполнитель ARTEMIS работает в отдельных пространствах процессов и монтирований
под UID приложения. ADB принимает только локальное соединение. Супервизор
закрывает исполнитель и восстанавливает настройки ADB при остановке MCP.
