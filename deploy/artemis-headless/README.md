# S23 Control с headless ARTEMIS

Установите APK для S23, разрешите root в менеджере и сохраните ключ Gemini
в настройках приложения. Для подключения из ChatGPT используется обычная
настройка CloudPub в том же приложении.

При первом запуске MCP S23 Control сам скачивает ARM64-среду, сверяет SHA-256
из APK, распаковывает архив в каталог приложения, настраивает Android-отладку
по loopback и запускает CLI ARTEMIS. Готовность отображается на главном экране.
Для проверки в ChatGPT вызовите `android_artemis_status`.

CLI запускается в отдельном пространстве процессов и файловых монтирований
под UID приложения. Доступ к локальному Android идёт через ADB с ключом,
созданным для этой установки. Приложение проверяет, что ADB слушает только
loopback, а команды выполняются под Android shell. При остановке MCP
супервизор завершает CLI и восстанавливает прежние параметры ADB.

Движок работает в отдельной Ubuntu-среде внутри приложения. Python и
зависимости собираются на ARM64 из зафиксированной ревизии Google ARTEMIS.
Gemini вызывается через API. Архив среды загружается один раз для каждой версии
среды. Автоматический запуск на физическом S23 требуется проверить.
